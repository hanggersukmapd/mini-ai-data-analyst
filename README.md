# 🤖 Mini AI Data Analyst Agent

Aplikasi web interaktif berbasis **Python**, **Streamlit**, dan **Google Gemini API** yang dirancang untuk membantu pengguna menganalisis dataset (CSV/Excel) secara instan melalui pendekatan *conversational AI*.

## 🚀 Fitur Utama
* **Unggah Dataset Fleksibel:** Mendukung format file `.csv` dan `.xlsx`.
* **Pratinjau & Metrik Otomatis:** Menampilkan jumlah baris, kolom, serta pengecekan *missing values* secara instan.
* **Analisis Interaktif berbasis LLM:** Didukung oleh model **Gemini 3.6 Flash** untuk menjawab pertanyaan, memberikan wawasan mendalam, dan merekomendasikan langkah pengolahan data.

## 🛠️ Tech Stack
* **Bahasa Pemrograman:** Python
* **Antarmuka Web:** Streamlit
* **Pengolahan Data:** Pandas, Openpyxl
* **Kecerdasan Buatan:** Google GenAI SDK (`google-genai`)
